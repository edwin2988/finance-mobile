## 1. 项目概述

### 1.1 产品名称
陈大哥的理财账本 - 手机版

### 1.2 产品定位
一款面向 Android 用户的个人理财账户管理工具，支持触控操作，界面简洁，操作便捷。

### 1.3 核心特性
- **触控优化**：大按钮、易操作
- **离线使用**：数据本地存储
- **数据同步**：支持与桌面版导入导出
- **简洁界面**：专注核心功能

### 1.4 目标用户
- 需要在手机上随时记录理财数据的用户
- 陈大哥理财账本桌面版用户

## 2. 核心功能需求

### 2.1 账户总览功能
**需求描述：** 展示所有账户的汇总信息

**功能点：**
- [ ] 列表展示所有账户
- [ ] 显示每个账户的最新估值
- [ ] 显示本期盈亏（红色盈利，绿色亏损）
- [ ] 显示年化收益率
- [ ] 下拉刷新数据
- [ ] 点击账户查看详情

### 2.2 快速录入功能
**需求描述：** 快速录入单条估值记录

**功能点：**
- [ ] 日期选择器（默认今天）
- [ ] 账户名称输入
- [ ] 估值金额输入（数字键盘）
- [ ] 一键保存
- [ ] 保存后清空输入框

### 2.3 批量录入功能
**需求描述：** 支持一次性录入多条记录

**功能点：**
- [ ] 添加多条记录（日期 + 账户 + 估值）
- [ ] 支持删除单行
- [ ] 批量保存
- [ ] 数据验证（金额必须为数字）

### 2.4 账户详情功能
**需求描述：** 查看单个账户的所有记录

**功能点：**
- [ ] 列表展示该账户所有记录
- [ ] 按日期倒序排列
- [ ] 支持编辑记录
- [ ] 支持删除记录
- [ ] 支持添加新记录

### 2.5 数据管理功能
**需求描述：** 数据导入导出

**功能点：**
- [ ] 导出为 CSV 文件
- [ ] 从 CSV 导入数据
- [ ] 支持文件选择器
- [ ] 自动识别编码（UTF-8/GBK）

### 2.6 设置功能
**功能点：**
- [ ] 清空所有数据（需确认）
- [ ] 查看数据量统计
- [ ] 关于页面
- [ ] 盈亏预警阈值设置

## 3. 界面设计需求

### 3.1 主界面布局
```
┌─────────────────────────┐
│  陈大哥的理财账本  📊   │
├─────────────────────────┤
│ [账户总览] [快速录入]    │
│ [批量录入] [数据管理]    │
│ [设置]                  │
├─────────────────────────┤
│ 总估值：¥123,456        │
│ 今日盈亏：+2,345 (红色) │
└─────────────────────────┘
```

### 3.2 账户总览页
- 列表形式展示
- 每项显示：账户名、最新估值、盈亏、年化
- 点击可查看详情
- 支持左右滑动删除

### 3.3 快速录入页
- 日期选择器（大按钮）
- 账户名称输入框
- 金额输入框（数字键盘）
- 保存按钮（大按钮，底部）

### 3.4 批量录入页
- 可添加多行记录
- 每行：日期 + 账户 + 金额
- 添加按钮、保存按钮

### 3.5 颜色规范
- **主色调**：#2196F3 (蓝色)
- **盈利**：#F44336 (红色)
- **亏损**：#4CAF50 (绿色)
- **背景**：#FFFFFF (白色)
- **文字**：#000000 (黑色)

### 3.6 字体规范
- **标题**：24sp
- **正文**：16sp
- **按钮**：18sp
- **数字**：20sp (金额)

## 4. 数据管理需求

### 4.1 数据存储
- **格式**：JSON
- **位置**：应用私有目录
- **文件**：`finance_data_v5.json`
- **编码**：UTF-8

### 4.2 数据备份
- 支持导出到本地文件
- 支持从 CSV 导入
- 自动备份（可选）

### 4.3 数据模型
```json
{
  "date": "2026-03-29",
  "account": "招商银行",
  "current_value": 10000.00
}
```

## 5. 技术实现要求

### 5.1 技术栈
- **框架**：Kivy 2.3.0+
- **打包工具**：Buildozer 1.5.0+
- **Python**：3.8+
- **依赖库**：
  - kivy
  - kivywidgets
  - python-dateutil

### 5.2 项目结构
```
理财记账手机版/
├── main.py                 # 主程序入口
├── finance_app_mobile.py   # 主应用类
├── screens/
│   ├── overview.py         # 账户总览页
│   ├── quick_entry.py      # 快速录入页
│   ├── batch_entry.py      # 批量录入页
│   ├── detail.py           # 账户详情页
│   └── settings.py         # 设置页
├── widgets/
│   ├── account_card.py     # 账户卡片组件
│   └── numpad.py           # 数字键盘
├── utils/
│   ├── data_manager.py     # 数据管理
│   └── csv_helper.py       # CSV 导入导出
├── data/
│   └── finance_data_v5.json
├── buildozer.spec          # Buildozer 配置
└── requirements.txt        # Python 依赖
```

### 5.3 权限要求
```xml
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
```

### 5.4 代码规范
- 类命名：大写开头，如 `OverviewScreen`
- 函数命名：小写 + 下划线，如 `load_data`
- 注释：中文注释，清晰易懂
- 异常处理：所有外部操作都要 try-except

## 6. 打包发布

### 6.1 Buildozer 配置
- **包名**：com.chendag.finance
- **应用名**：陈大哥的理财账本
- **版本号**：1.0.0
- **最低 Android 版本**：5.0 (API 21)
- **目标 Android 版本**：13.0 (API 33)

### 6.2 打包命令
```bash
# 初始化
buildozer init

# 构建 APK
buildozer -v android debug

# 构建发布版
buildozer -v android release

# 清理
buildozer android clean
```

### 6.3 APK 输出
- **调试版**：`bin/陈大哥的理财账本-1.0.0-debug.apk`
- **发布版**：`bin/陈大哥的理财账本-1.0.0-release.apk`

### 6.4 安装包大小
- **目标**：< 20MB
- **优化**：去除未使用资源，压缩图片
